## Brief

이 토너먼트는 "드래프트를 앞으로 **어떤 화면·레이아웃·무드·리모컨으로 보여줄지**" — 즉
picky-client **드래프트 리뷰 페이지(하네스) 그 자체의 디자인**을 정한다. (일반적인
Round 1 = 서비스 톤&매너와 달리, 사용자가 이 라운드의 심사 대상을 "드래프트 페이지
자체"로 지정함.) 각 시안은 완성형 목업 한 화면이며, 우승작이 앞으로의 하네스 룩이 된다.

- 각 시안 목업의 갤러리 슬롯에 "리뷰되는 시안"으로 **표현되는 콘텐츠 = 실제 `/` 루트
  (회롱이 홈: 이메일 입력 + 가이드) 페이지** (`RootPagePreview`, accent만 달리한 톤 변주 10개).
- 고정 제약: React 19 + TS(strict, verbatimModuleSyntax) + Vite + React Router v7(선언형
  `<Routes>`) + Tailwind v4 + framer-motion. 하네스는 `import.meta.env.DEV`에서만 라우팅.
- 표시 규율: 모바일 퍼스트, 더블 스크롤 금지, 키컬러 1 + 서브 ≤1, 실제 한국어 카피.

### 하네스 구조 (2단, /picky-drafts)
- `/picky-drafts` — 아코디언 메인(구 중립 셸 대체). 라운드를 펼쳐 후보 썸네일에 바로 접근.
  최신 라운드 기본 펼침·코랄, 결정 라운드는 우승 배지. Round 2는 hidden. `?round=N`으로 특정 라운드 펼쳐 진입.
- `/picky-drafts/{roundId}/{index}` — 개별 시안 풀스크린 + 좌상단 리모컨(목록 복귀 ·
  라운드 드롭다운 · 시안 페이저). 테마 토큰(다크 기본, 라이트 seam).
- 구 3단(`/drafts` · `/draft-round{N}` · `/draft-round{N}/{index}`)은 제거됨(#7 승격).
