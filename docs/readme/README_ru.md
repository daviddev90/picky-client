**Поручите дизайн своему агенту. Будьте требовательным клиентом. Доведите качество дизайна своего сервиса до предела.**

Сравнивайте реальные варианты UI/UX и выбирайте нужное направление. Когда вы утвердите дизайн, агент применит его к реальному экрану и проверит результат.

## Начните со своего агента

Скопируйте этот запрос в своего агента для разработки:

```text
Прочитай README по адресу https://github.com/daviddev90/picky-client.git и установи picky-client в своей среде агента.
```

Затем запросите первый раунд в проекте своего продукта:

```text
Используй picky-client, чтобы создать 3–5 вариантов компоновки этой панели управления. Сохрани существующие цвета, шрифты и функции и дай мне сравнить варианты в браузере перед выбором.
```

Агент исследует примеры, создаёт варианты, проверяет их отображение в реальном браузере и предоставляет доступный вам URL для просмотра. Вы изучаете варианты и выбираете.

## Как проходит раунд

Эта схема объясняет процесс:

```mermaid
flowchart LR
    A[Определить экран и решение] --> B[Исследовать, создать и проверить варианты в браузере]
    B --> C[Вы сравниваете и выбираете]
    C --> D[Вы одобряете следующий раунд или утверждаете дизайн и его применение]
    D -->|Следующий раунд| A
```

Каждый раунд посвящён одному ещё не решённому аспекту дизайна. Ваш выбор сохраняется, поэтому следующий раунд развивает то, что вам уже понравилось.

| Что вы решаете | Что вы сравниваете |
|---|---|
| Настроение, визуальный характер или одинаково удобные композиции | Десять разных направлений |
| Компоновку, элементы управления, плотность или навигацию | От трёх до пяти обоснованных вариантов с компромиссами в удобстве использования |
| Остался один содержательный вариант | Обоснованную рекомендацию |
| Тема уже утверждена | Варианты, сохраняющие её цвета, характер шрифтов и материалы |

## Выберите, уточните, примените

Сообщите агенту, что вы выбрали и что нужно сделать дальше. Примеры запросов:

```text
Я выбираю #2. Затем предложи раунд по типографике, сохранив эту компоновку.
```

```text
Дизайн утверждён. Примени #2 к реальному экрану и проверь его поведение и состояния.
```

Прежде чем продолжить, агент ждёт вашего решения. Применение дизайна включает сохранение существующей функциональности, согласование выбранной компоновки с реальным экраном и проверку результата отображения.

## Что делает варианты полезными

- **Реальные ориентиры:** в каждом раунде исследуются сервисы с такой же функцией или похожей ролью, а также актуальные подходы к дизайну.
- **Честное сравнение:** все визуальные варианты используют общие проверенные тексты; утверждённые решения по дизайну сохраняются.
- **Удобные варианты:** отображение в браузере и навигация проверяются до передачи вам, а доступный URL позволяет оценивать варианты на вашем устройстве.
- **История решений:** в `docs/picky-client.md` вашего проекта записываются варианты, исследования, проверки и победители. Утверждённая спецификация сохраняется в `docs/picky-client-design.md`.
- **Чистая производственная сборка:** временная среда просмотра и строки её подключения к приложению удаляются, затем проверяется их отсутствие в итоговой сборке.

Предлагаемая среда просмотра использует React, TypeScript, Vite, React Router, Tailwind и Motion. Для других стеков адаптируются точки интеграции; нативные продукты используют веб-предпросмотр перед применением в собственном стеке. Среды с субагентами делегируют создание и проверку. В остальных средах этапы выполняются последовательно, а проверка тем же агентом отмечается в записи.

### Для устанавливающего агента

Соблюдай запрошенные пользователем способ и область установки. В остальных случаях используй указанный ниже нативный плагин для Codex или Claude Code, а для других сред используй соответствующий ID в Skills CLI. Нативные плагины по умолчанию устанавливаются для текущего пользователя; Skills CLI по умолчанию устанавливает в проект. Установи всю папку навыка, включая справочные материалы, скрипты и ресурсы. Убедись, что среда действительно обнаруживает навык, затем сообщи способ вызова и необходимые для этой среды действия по перезагрузке.

### Skills CLI

Основная версия навыка находится в [skills/picky-client](../../skills/picky-client). Запусти [Skills CLI](https://github.com/vercel-labs/skills) из папки проекта с Node.js 22.20.0 или новее:

```bash
npx skills add daviddev90/picky-client --skill picky-client
```

Выбери агента при запросе или укажи его явно:

```bash
npx skills add daviddev90/picky-client --skill picky-client --agent opencode -y
npx skills add daviddev90/picky-client --skill picky-client --agent antigravity -y
```

| Агент | ID `--agent` |
|---|---|
| Codex | `codex` |
| Claude Code | `claude-code` |
| OpenCode, включая oh-my-opencode | `opencode` |
| Antigravity IDE | `antigravity` |
| Antigravity CLI | `antigravity-cli` |
| Cursor | `cursor` |
| GitHub Copilot | `github-copilot` |
| Gemini CLI | `gemini-cli` |
| Cline | `cline` |
| Windsurf | `windsurf` |

Добавь `-g` для установки в общую папку агента для текущего пользователя. Для ручной установки в проект скопируй всю папку `skills/picky-client` в `.agents/skills/`, поддерживаемую [OpenCode](https://opencode.ai/docs/skills/) и [Antigravity](https://antigravity.google/docs/skills?app=antigravity-ide). oh-my-opencode использует установку навыков OpenCode.

### Плагин Claude Code

В терминале, Claude Code 2.1.292 или новее:

```bash
claude plugin install picky-client --marketplace daviddev90/picky-client
```

Для более старых версий:

```bash
claude plugin marketplace add daviddev90/picky-client
claude plugin install picky-client@daviddev90
```

В сеансе версия 2.1.275 или новее поддерживает `/plugin install picky-client --marketplace daviddev90/picky-client`. См. [установку плагинов Claude Code](https://code.claude.com/docs/en/discover-plugins).

### Плагин Codex

```bash
codex plugin marketplace add daviddev90/picky-client
codex plugin add picky-client@daviddev90
```

Используй `/plugins` внутри Codex для просмотра плагинов. См. [справочник Codex CLI](https://learn.chatgpt.com/docs/cli/reference).

Оба плагина используют основную папку `skills/` в корне. Корневой [plugin.json](../../plugin.json) описывает переносимый плагин и плагин Codex; [.claude-plugin/plugin.json](../../.claude-plugin/plugin.json) обеспечивает совместимость с Claude Code. См. [упаковку плагинов](https://developers.openai.com/plugins/build/plugins).
