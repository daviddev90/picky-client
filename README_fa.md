**طراحی را به عامل خود بسپارید. مشتری سخت‌پسند باشید. کیفیت طراحی سرویس خود را به بالاترین حد برسانید.**

پیش‌طرح‌های واقعی UI/UX را مقایسه کنید و مسیر دلخواهتان را انتخاب کنید. وقتی طراحی را نهایی کردید، عامل آن را روی صفحهٔ واقعی اعمال می‌کند و نتیجه را بررسی می‌کند.

## با عامل خود شروع کنید

این درخواست را در عامل برنامه‌نویسی خود کپی کنید:

```text
README را در https://github.com/daviddev90/picky-client.git بخوان و picky-client را در محیط عامل خودت نصب کن.
```

سپس در پروژهٔ محصولتان، دور اول را درخواست کنید:

```text
با picky-client برای این داشبورد 3–5 پیش‌طرح چیدمان بساز. رنگ‌ها، قلم‌ها و قابلیت‌های موجود را حفظ کن و اجازه بده پیش از انتخاب، پیش‌طرح‌ها را در مرورگر مقایسه کنم.
```

عامل نمونه‌ها را بررسی می‌کند، گزینه‌ها را می‌سازد، نمایش آن‌ها را در مرورگر واقعی بررسی می‌کند و یک URL قابل‌دسترسی برای بازبینی به شما می‌دهد. شما گزینه‌ها را مرور می‌کنید و انتخاب می‌کنید.

## هر دور چگونه پیش می‌رود

این نمودار روند کار را توضیح می‌دهد:

```mermaid
flowchart LR
    A[صفحه و تصمیم را مشخص کنید] --> B[تحقیق کنید، پیش‌طرح بسازید و در مرورگر بررسی کنید]
    B --> C[شما مقایسه و انتخاب می‌کنید]
    C --> D[دور بعد را تأیید می‌کنید یا طراحی را نهایی و اعمال می‌کنید]
    D -->|دور بعد| A
```

هر دور دربارهٔ یک جنبهٔ هنوز تعیین‌نشدهٔ طراحی تصمیم می‌گیرد. انتخاب‌های شما حفظ می‌شوند تا دور بعد بر پایهٔ چیزهایی شکل بگیرد که قبلاً پسندیده‌اید.

| تصمیم شما | آنچه مقایسه می‌کنید |
|---|---|
| حال‌وهوا، شخصیت بصری یا ترکیب‌بندی‌هایی با کاربردپذیری یکسان | ده مسیر متمایز |
| چیدمان، کنترل‌ها، تراکم یا پیمایش | سه تا پنج گزینهٔ مستند با توضیح بده‌بستان‌های کاربردپذیری |
| فقط یک گزینهٔ معنادار باقی مانده است | یک پیشنهاد همراه با دلیل |
| تم از قبل تعیین شده است | گزینه‌هایی که رنگ‌ها، هویت قلم‌ها و متریال‌های تم را حفظ می‌کنند |

## انتخاب کنید، اصلاح کنید، اعمال کنید

به عامل بگویید چه چیزی را انتخاب کرده‌اید و قدم بعد چه باشد. نمونهٔ درخواست‌ها:

```text
من #2 را انتخاب می‌کنم. سپس یک دور برای تایپوگرافی پیشنهاد بده و این چیدمان را حفظ کن.
```

```text
طراحی نهایی شده است. #2 را روی صفحهٔ واقعی اعمال کن و رفتار و حالت‌های آن را بررسی کن.
```

عامل پیش از ادامه منتظر تصمیم شما می‌ماند. اعمال طراحی شامل حفظ قابلیت‌های موجود، سازگار کردن چیدمان انتخاب‌شده با صفحهٔ واقعی و بررسی نتیجهٔ نمایش است.

## چه چیزی انتخاب‌ها را مفید می‌کند

- **منابع واقعی:** در هر دور، سرویس‌هایی با همان قابلیت یا نقشی مشابه و همچنین شیوه‌های روز طراحی بررسی می‌شوند.
- **مقایسهٔ منصفانه:** گزینه‌های بصری از متن‌های مشترک و بازبینی‌شده استفاده می‌کنند؛ تصمیم‌های نهایی‌شدهٔ طراحی ثابت می‌مانند.
- **پیش‌طرح‌های قابل‌استفاده:** نمایش در مرورگر و پیمایش پیش از تحویل بررسی می‌شوند و یک URL قابل‌دسترسی برای بازبینی روی دستگاه شما ارائه می‌شود.
- **سابقهٔ تصمیم‌ها:** فایل `docs/picky-client.md` در پروژهٔ شما گزینه‌ها، تحقیق، بررسی‌ها و برنده‌ها را ثبت می‌کند. مشخصات نهایی در `docs/picky-client-design.md` ذخیره می‌شوند.
- **بیلد تولیدی تمیز:** محیط موقت بازبینی و خطوط کد اتصال آن به برنامه حذف می‌شوند و خروجی بیلد تولیدی بررسی می‌شود تا این موارد در آن نباشند.

محیط بازبینی ارائه‌شده از React، TypeScript، Vite، React Router، Tailwind و Motion استفاده می‌کند. در پشته‌های فناوری دیگر، نقاط اتصال آن سازگار می‌شوند؛ محصولات بومی پیش از اعمال طراحی در پشتهٔ خود از پیش‌نمایش وب استفاده می‌کنند. محیط‌هایی که عامل‌های فرعی دارند، ساخت و بازبینی را به آن‌ها واگذار می‌کنند. محیط‌های دیگر مراحل را به‌ترتیب اجرا می‌کنند و ثبت می‌کنند که بازبینی را همان عامل انجام داده است.

### برای عاملی که نصب را انجام می‌دهد

روش و دامنهٔ نصب درخواست‌شدهٔ کاربر را رعایت کن. اگر کاربر آن‌ها را مشخص نکرده است، برای Codex یا Claude Code از مسیر افزونهٔ بومی زیر و برای محیط‌های دیگر از ID مناسب در Skills CLI استفاده کن. افزونه‌های بومی به‌طور پیش‌فرض برای کاربر فعلی نصب می‌شوند؛ Skills CLI به‌طور پیش‌فرض در پروژه نصب می‌کند. پوشهٔ مهارت را کامل، همراه با منابع، اسکریپت‌ها و فایل‌های موردنیاز نصب کن. بررسی کن که محیط واقعاً مهارت را شناسایی می‌کند، سپس روش فراخوانی و مراحل بارگذاری مجدد موردنیاز آن محیط را گزارش کن.

### Skills CLI

مهارت مرجع در [skills/picky-client](skills/picky-client) قرار دارد. [Skills CLI](https://github.com/vercel-labs/skills) را از پوشهٔ پروژه با Node.js 22.20.0 یا جدیدتر اجرا کن:

```bash
npx skills add daviddev90/picky-client --skill picky-client
```

هنگام پرسش، عامل را انتخاب کن یا آن را مستقیماً مشخص کن:

```bash
npx skills add daviddev90/picky-client --skill picky-client --agent opencode -y
npx skills add daviddev90/picky-client --skill picky-client --agent antigravity -y
```

| عامل | ID مربوط به `--agent` |
|---|---|
| Codex | `codex` |
| Claude Code | `claude-code` |
| OpenCode، شامل oh-my-opencode | `opencode` |
| Antigravity IDE | `antigravity` |
| Antigravity CLI | `antigravity-cli` |
| Cursor | `cursor` |
| GitHub Copilot | `github-copilot` |
| Gemini CLI | `gemini-cli` |
| Cline | `cline` |
| Windsurf | `windsurf` |

برای نصب در محل عامل که در سطح کاربر در دسترس است، `-g` را اضافه کن. برای نصب دستی در پروژه، کل پوشهٔ `skills/picky-client` را در `.agents/skills/` کپی کن که [OpenCode](https://opencode.ai/docs/skills/) و [Antigravity](https://antigravity.google/docs/skills?app=antigravity-ide) از آن پشتیبانی می‌کنند. oh-my-opencode از روش نصب مهارت OpenCode استفاده می‌کند.

### افزونهٔ Claude Code

در ترمینال، با Claude Code 2.1.292 یا جدیدتر:

```bash
claude plugin install picky-client --marketplace daviddev90/picky-client
```

روش جایگزین برای نسخه‌های قدیمی‌تر:

```bash
claude plugin marketplace add daviddev90/picky-client
claude plugin install picky-client@daviddev90
```

درون جلسه، نسخهٔ 2.1.275 یا جدیدتر از `/plugin install picky-client --marketplace daviddev90/picky-client` پشتیبانی می‌کند. [نصب افزونه‌های Claude Code](https://code.claude.com/docs/en/discover-plugins) را ببینید.

### افزونهٔ Codex

```bash
codex plugin marketplace add daviddev90/picky-client
codex plugin add picky-client@daviddev90
```

برای مرور افزونه‌ها در Codex از `/plugins` استفاده کنید. [مرجع Codex CLI](https://learn.chatgpt.com/docs/cli/reference) را ببینید.

هر دو افزونه از پوشهٔ مرجع `skills/` در ریشهٔ مخزن استفاده می‌کنند. [plugin.json](plugin.json) در ریشه، افزونهٔ قابل‌انتقال/Codex را بسته‌بندی می‌کند؛ [.claude-plugin/plugin.json](.claude-plugin/plugin.json) سازگاری با Claude Code را فراهم می‌کند. [بسته‌بندی افزونه‌ها](https://developers.openai.com/plugins/build/plugins) را ببینید.
